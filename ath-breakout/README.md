# ath-breakout(過去最高値ブレイクのその後)

時価総額上位500の日本株について、「久しぶりに過去最高値を更新した日(ブレイク)」を探し、
そのあと株価がどう動いたかを集計するページです。サーバーは持たない静的サイトです。

## 公開URL

https://git-san-934.github.io/portal/ath-breakout/

## 判定のしかた

- 株価は分割調整済みの日次終値(配当は含まない)
- 上場(データ開始)から60営業日(約3ヶ月)たつまでは判定しない(上場直後はすぐ最高値になるため)
- それまでの最高値を上回った日のうち、前回の最高値から60営業日(約3ヶ月)以上あいたものを1回の「ブレイク」として数える
  (高値更新が何日も続いても1回だけ数える)
- 画面では「前回の最高値から 3ヶ月以上 / 1年以上 / 3年以上」で絞り込める

## 見られるもの

- 要約: ブレイクの件数、1年後に上がっていた割合、1年後にTOPIXに勝った割合
- 1週・1ヶ月・3ヶ月・6ヶ月・1年後の騰落率(平均・中央値・上昇した割合)と、TOPIX連動ETF(1306)を差し引いた超過リターン
- ブレイク日を100とした前後の値動き(中央値と25〜75%の範囲)。株価そのままと TOPIX比 を切り替え
- 直近3ヶ月以内にブレイクした銘柄の一覧。値下がりして見なくてよくなった銘柄は「外す」ボタンで一覧から外せる
  (外した銘柄はこの端末のブラウザにだけ記録。その後また最高値を更新したら自動で一覧に戻る。集計には影響しない)
- ブレイクの一覧。銘柄を押すと、データ開始からの週足チャート(対数目盛り)にブレイクした日の印をつけて表示
- 絞り込み: 前回の最高値からの間隔 / ブレイクした時期(全期間・2013年以降・直近5年) / 対象(上位500・上位100)

## データについて

- 対象銘柄: [tse-price-db](https://git-san-934.github.io/tse-price-db/) の `latest.json` から時価総額上位500銘柄を選ぶ
  (取得できないときは前回の `data/universe.json` を使う)
- 株価: Yahoo Finance(yfinance 経由)。取得できる最も古い日から。登録・費用は不要です
- `.github/workflows/update-ath-breakout.yml` が平日 16:30(JST)頃に `scripts/fetch_ath.py` を実行し、
  `data/` を更新してコミットし、GitHub Pages を再デプロイします
- 手動で更新したいときは、GitHub の Actions タブ →「過去最高値ブレイクデータ更新」→「Run workflow」
- 取得できた銘柄が8割に満たないときはデータを上書きしません

## 注意点

- 日本株は多くが2000年前後からのデータのため、それより前(バブル期など)の高値は含みません。
  「データ取得期間内の最高値」です
- 今上場している銘柄だけが対象のため、上場廃止になった銘柄の結果は入っていません(生存者バイアス)。実際より良く見えやすくなります
- 同じ時期に多くの銘柄がブレイクしやすい(上げ相場に集中する)ので、件数が多くても独立した結果とは限りません
- yfinance は Yahoo Finance の非公式ラッパーのため、予告なく動かなくなる可能性があります
- **投資助言ではありません。** 売買判断はご自身の責任で行ってください

## ファイル構成

- `index.html` — ページ本体
- `assets/style.css` — スタイル(portal / sector-etf と同じデザイントークン)
- `assets/app.js` — 集計・チャート描画・絞り込み
- `scripts/fetch_ath.py` — 株価を取得し、ブレイクを判定して `data/` を作るスクリプト
- `data/events.json` — ブレイク一覧と銘柄ごとの要約(自動生成)
- `data/stocks/<code>.json` — 銘柄ごとの週足終値(自動生成)
- `data/universe.json` — 対象銘柄(自動生成)

判定の条件を変えるときは `scripts/fetch_ath.py` の `MIN_HISTORY` / `MIN_GAP` / `UNIVERSE_SIZE` を書き換えてください。
