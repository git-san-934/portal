# ad-watch(広告費ウォッチ)

「広告宣伝費を大きく増やして、売上もちゃんと伸びている会社」を探すページです。
広告費の増加は売上より先に表に出るので、成長の手がかりになることがあります。
ただし広告費はコストなので、売上・営業利益とセットで判定します。サーバーは持たない静的サイトです。

## 公開URL

https://git-san-934.github.io/portal/ad-watch/

## 見られるもの

- 会社ごとのカード: 直近の決算期の広告費・売上の伸び(前年比)、売上に占める広告費、営業利益率
- 判定(直近の決算期と、その前の年を比べる)
  - 広告が効いている: 広告費+10%以上、売上+10%以上、営業利益は黒字で前年から2割以上減っていない
  - 空振り気味: 広告費+10%以上なのに、売上の伸びが+3%未満
  - 赤字に注意: 広告費+10%以上で、営業利益が赤字
  - 広告増: 広告費+10%以上で、上のどれにもあてはまらない
- 「自社株買い中」の印: 直近45日以内に自己株券買付状況報告書が出ている会社
- 年ごとの数字: 売上高は最大5期、広告宣伝費は最大4期

## データについて

- `scripts/fetch_ad.py` が EDINET API から集める(`EDINET_API_KEY` が必要。リポジトリの Secrets に登録済みのものを使う)
  1. 書類一覧(直近800日)から、国内上場企業の有価証券報告書と自己株券買付状況報告書を探す → `data/edinet_docs.json`
  2. 全社の最新の有価証券報告書を読み、広告宣伝費が載っていた会社だけ2年前の報告書も読む → `data/ad.json`
- 広告宣伝費は損益計算書か「販売費及び一般管理費のうち主要な費目」の注記から、要素名に Advertis を含む項目を読む。
  載せていない会社は対象外(`noad`)。連結を優先し、なければ単体
- 時間がかかるので100分で打ち切り、次の実行で続きを取る。最初は全社そろうまで数日かかる
- `.github/workflows/update-ad-watch.yml` が毎日 6:30(JST)頃に実行し、データをコミットして GitHub Pages を再デプロイします
- 手動で更新したいときは、GitHub の Actions タブ →「広告費ウォッチ データ更新(EDINET)」→「Run workflow」

## 注意点

- 自動で読み取っているため、会社によっては広告宣伝費以外の項目(販売促進費との合計など)を拾っていることがあります
- 数字は年1回の有価証券報告書のものなので、最大1年ほど前の決算期のことがあります
- **投資助言ではありません。** 売買判断はご自身の責任で行ってください

## ファイル構成

- `index.html` — ページ本体
- `assets/style.css` — スタイル(portal と同じデザイントークン)
- `assets/app.js` — 判定・絞り込み・一覧の描画
- `scripts/fetch_ad.py` — EDINET から集めて `data/ad.json` を作るスクリプト
