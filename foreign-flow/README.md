# foreign-flow(海外投資家の需給)

海外投資家が買えば株価は上がり、空売りすれば下がります。どちらも同時に起きるので、銘柄ごとに
「買いの圧力」と「売りの圧力(空売り)」のどちらが強まっているかを、4週・13週の変化で比べるページです。
サーバーは持たない静的サイトです。

## 公開URL

https://git-san-934.github.io/portal/foreign-flow/

## 表示している内容

- 市場全体: 東証プライムでの海外投資家の週ごとの買い越し・売り越し(直近26週の棒グラフと月次)
- 海外マネーが向かいやすい銘柄ベスト5: TOPIX 500 から毎日選び直し、理由つきで表示
- 持ち株と追加した銘柄の一覧(スコア順)と銘柄カード
  - 空売り残高(0.5%以上の報告の合計)と4週・13週の増減、13週騰落率(TOPIX比)、出来高
  - 売りの圧力・買いの圧力の点数、判定の理由
  - 株価と空売り残高の26週チャート、空売りしている機関の一覧、大量保有報告書(EDINET キーがあるとき)
- 判定の仕組み(計算式)

## 銘柄の追加

- ページの「銘柄を追加」に銘柄コードを入れると、その銘柄が一覧とカードに加わります。
  追加した銘柄は、閲覧しているブラウザの localStorage にだけ保存します。
  表示できるのは `flow.json` にある銘柄(TOPIX 500、持ち株、ウォッチリスト、空売りの報告がある銘柄)です
- どの端末でも毎日追跡したい銘柄は `data/watchlist.json` の `stocks` に `{ "code": "2201", "name": "森永製菓" }` の形で追加します
- 持ち株は `holdings/data/check.json` の日本株を自動で読みます(米国株は対象外)

## データについて

- `data/flow.json` — 自動生成(手で編集しない)。`.github/workflows/update-foreign-flow.yml` が平日 19:30(JST)頃に
  `scripts/fetch_flow.py` を実行してコミットし、GitHub Pages を再デプロイします
  - 手動で更新したいときは、GitHub の Actions タブ →「海外投資家の需給データ更新」→「Run workflow」
  - 空売り残高か株価が取れなかったときは `flow.json` を上書きしません
- 出典
  - 空売り残高: JPX「空売り残高に関する情報」(毎営業日、直近12か月分を読み直して推移を作る。ファイルは Actions のキャッシュで使い回す)
  - 海外投資家の売買: JPX「投資部門別売買状況」(週次・月次。過去の週は前回の `flow.json` から引き継ぐ)
  - TOPIX 500 の銘柄: JPX の TOPIX 構成銘柄一覧
  - 株価・出来高: Yahoo Finance(yfinance 経由)
  - 大量保有報告書: EDINET API(任意)
- 大量保有報告書を使うには、EDINET で API キー(無料)を発行し、リポジトリの
  Settings → Secrets and variables → Actions に `EDINET_API_KEY` という名前で登録します。
  未登録なら大量保有の点数を使わずに判定します。読み取った報告は `data/edinet_cache.json` に保存します
- **投資助言ではありません。** 判定は需給の整理であり、売買判断はご自身の責任で行ってください

## ファイル構成

- `index.html` — ページ本体
- `assets/style.css` — スタイル(portal / holdings と同じデザイントークン)
- `assets/app.js` — データ読み込み・銘柄追加・チャート描画
- `scripts/fetch_flow.py` — 公開データを集めて `data/flow.json` を作るスクリプト
- `data/watchlist.json` — 持ち株以外に毎日追跡する銘柄
