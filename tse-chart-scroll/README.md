# tse-chart-scroll

[東証株価データベース](https://git-san-934.github.io/tse-price-db/)の全銘柄の5年チャート(週次終値)を、
チャートのみ次々に表示するWebアプリです。下にスクロールすると次の銘柄のチャートが読み込まれます。

サーバーは持たず、すべてブラウザ内で動作する静的サイトです。

## 公開URL

[portal](https://git-san-934.github.io/portal/) リポジトリの一部として、次のURLで見られます:

https://git-san-934.github.io/portal/tse-chart-scroll/

## 機能

- 東証上場銘柄(約4,449銘柄)の5年チャート(週次終値)を1銘柄1カードで表示
- 下にスクロールすると次の銘柄が自動で読み込まれる(無限スクロール)
- 上部の検索欄で銘柄コード・銘柄名で絞り込み可能
- 並び替えボタンで表示順を変更可能(時価総額 [初期表示] ・終値・売買代金・PBR・PER・配当利回り)。同じボタンをもう一度押すと降順⇔昇順を切り替え、別のボタンを押すとそちらの降順から開始。値なし銘柄は順序に関わらず末尾
- 各カードに時価総額・終値・売買代金・PBR・PER・配当利回りの6指標をすべて表示し、現在の並び替え対象をハイライト
- スマートフォンでの表示を確認済み(横スクロールなし、並び替えボタンは44px以上のタップ領域を確保)
- 「スライドショー」ボタンで、スクロールせず1銘柄ずつ全画面表示に切り替え可能。速度ボタン(1秒/2秒/3秒 [初期値] /5秒)で自動再生の間隔を調整可能(一時停止可)、前へ/次へボタン、キーボード矢印キー・スペースキー・Escキー、スマホでの左右スワイプに対応
- 高値圏/安値圏/中立の判定バッジを各カードに表示
- チャートの縦軸に大まかな目盛り(価格の水平線と概算ラベル)を表示
- 長時間スクロールしてもブラウザが重くならないよう、画面から離れた古いカードは自動的に間引かれます

## データについて

- データ取得元: [tse-price-db](https://git-san-934.github.io/tse-price-db/) が生成する
  `data/latest.json`(銘柄一覧・直近値)と `data/history_weekly/<code>.json`(5年分・週次終値)を
  ブラウザから直接 fetch します(GitHub Pages は全ファイルに CORS が有効なため、別オリジンからでも取得できます)
- このアプリ自体はデータを取得・保存しません。データの更新頻度・仕組みは tse-price-db 側の README を参照してください
- **投資助言ではありません。** 表示される内容を参考に、最終的な売買判断はご自身で行ってください

## ファイル構成

- `index.html` — ページ本体
- `assets/style.css` — スタイル(tse-price-db/portal と同系統のデザイントークンを使用)
- `assets/app.js` — 銘柄一覧の取得・無限スクロール・チャート描画ロジック

デプロイは portal リポジトリの `.github/workflows/deploy.yml` が `main` への push のたびに
リポジトリ全体をまとめて GitHub Pages に公開する形で行われます(このアプリ専用のワークフローはありません)。
