売りルールの決め方と過去の成績

毎日1万円＋暴落時の追加(ふつう)を続けた場合に、「売らない」と「この売りルール」を比べました。倍率は、最後に全部売ったときの税引後の資産 ÷ 自分で入れたお金です。2017年12月より前は日経平均の値動き×4.3倍で作った仮の基準価額、それ以降は実際の基準価額を使い、1996年から約3ヶ月ずつ開始日をずらして計算しています。

続けた期間比べた回数売りルールが勝った差(中央値)いちばん負けた回途中の最大の下げ
1年120回33%±0%−14%−59% → −55%
3年112回79%+8%−20%−80% → −77%
5年104回97%+20%−5%−87% → −83%
5年(2025年までに終わる回だけ)101回98%+19%−3%—

1年だと、半分以上の回は合図が一度も出ず「売らない」と同じ結果です(合図が出た回だけで見ると中央値 +2%)。実際の基準価額だけの期間(2018年1月〜)では、売らない ×6.2 → 売りルール ×12.4、途中の最大の下げは −87% → −77% でした(2025年末まで: ×4.5 → ×7.8)。

  • なぜ「1年前の3倍」か: 4.3ブルが1年で3倍になるのは、日経平均が1年で3割ほど上がったときです。過去にこの合図が出た日から1年後は、中央値で −22%、64%の日で下がっていました(どの日でも1年後は中央値 −9%、下がったのは54%)。上がりすぎたあとは、4.3倍の大きな下げが来やすいということです。1年前の2.5倍・3.5倍でも結果はほぼ同じで、たまたま当たった数字ではありません。
  • なぜ1/4ずつか: 一度に全部売ると、そのあとも上がり続けた年(2013年、2026年前半)に大きく取り逃します。1/5〜1/3ならどれでも結果は近く、間をとって1/4にしました。合図は1ヶ月(20営業日)に1回までです。
  • 売ったお金をどう戻すか: ここがいちばん大事でした。売ったお金を現金のまま置いておくと、長く続けるほど「売らない」に負けます(最後まで続けた回の中央値で半分以下)。暴落買いの追加資金に先に回し、残りは基準価額が200日平均より20%以上安い日に、残りの10%ずつ買い戻すと、全期間で勝ちました。
  • ほかに試してだめだったもの: 「含み益が2倍になったら売る」は5年で勝ったのが69%、「200日平均より50%高くなったら売る」は87%でしたが、負けた回の負け方が大きく(最大 −39%)、採りませんでした。下げはじめに逃げる売り方(高値から何%下がったら売る)は、暴落で買い増すいまのルールと逆向きになるので試していません。

実際の基準価額での売りの合図と、そのあとの値動き

ルールと注意点

  • 判定の仕方: その日の基準価額が、直近20営業日の最高値から何%下がったかで決めます。前日比ではなく「20日高値から」の方が、過去の検証で成績が安定していました。
  • 大口買いと上限: −50%以下は30万円、−70%以下は50万円の大口買いです。リーマンショックのように下げが何ヶ月も続くと際限なく買い続けることになるので、大口買いは1回の暴落で合計200万円までにしています(使い切ったあとは10万円ずつ。60営業日のあいだ大口の合図がなければ、次は別の暴落として数え直します)。
  • 注文のタイミング: 基準価額はその日の夜に出るので、追加買いは次の営業日の注文で行う前提です(過去の成績もこの前提で計算しています)。
  • 追加資金の用意: 暴落は続けて来ます。2020年3月のように、1ヶ月で何十万円も追加する年があります。下の表の「追加額」の最大の年くらいは、別に現金を取っておくのが目安です。
  • 売り時: 基準価額が1年前(245営業日前)の3倍以上になった日は、次の営業日に持ち分の1/4を売ります(次の合図まで20営業日あけます)。売ったお金は暴落時の追加買いに先に使い、残りは基準価額が200日平均より20%以上安い日に10%ずつ買い戻します。特定口座なら売った利益に約20%の税金がかかります(成績はこの税金を引いて計算しています)。
  • 償還に注意: この投信の信託期間は 2027年9月7日までです(延長されることもあります)。延長されなければその時点で全部お金に戻るので、売りルールの差が出るのは「この先も4.3倍の商品を持ち続ける」場合です。1年だけだと、売りルールの有無で結果はほとんど変わりません。
  • 持ちすぎに注意: 4.3倍の商品は、過去に最高値から約87%下がったことがあります。資産全体に占める割合を30〜50%までにすると、全体の下げ幅がかなり小さくなりました。
  • 過去の成績は将来を約束しません。 投資助言ではありません。売買判断はご自身の責任で行ってください。
