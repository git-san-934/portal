# nikkei43(日経4.3ブル 暴落買いナビ)

SBI日本株4.3ブル(協会コード 8931317C)の基準価額を毎日分析して、毎日の積立(初期値 1万円)に
上乗せする「暴落時の追加額」と、上がりすぎたときの「売り時」の目安を出すページです。サーバーは持たない静的サイトです。

## 公開URL

https://git-san-934.github.io/portal/nikkei43/

## 追加買いのルール

その日の基準価額が「直近20営業日の最高値」から何%下がったかで、次の営業日の追加額を決めます。

| 20日高値からの下落 | 追加額(ふつう) | 控えめ(½) | 多め(×2) |
|---|---|---|---|
| −30%より浅い | なし | なし | なし |
| −30%以下 | 1万円 | 0.5万円 | 2万円 |
| −35%以下 | 2万円 | 1万円 | 4万円 |
| −40%以下 | 3万円 | 1.5万円 | 6万円 |
| −45%以下 | 4万円 | 2万円 | 8万円 |
| −50%以下 | 5万円 | 2.5万円 | 10万円 |
| −55%以下 | 6万円 | 3万円 | 12万円 |

合図(−30%以下)が続く間は、2日に1回だけ追加します(続いた1日目・3日目・5日目…。−30%より上に戻ったら数え直し)。
2026-11-07 に、手元の現金が続く範囲にするため、30万円・50万円の大口買い(1回の暴落で200万円まで)があった以前のルールから変えました。

2018年1月〜2026年11月5日の実際の基準価額で検証すると(毎日1万円+ふつう、合図の翌営業日に購入)、
投資額あたりの損益率は 毎日だけ +377% → +416%(以前の大口ありのルールは +532%)。
追加の現金は年平均 約33万円、最も多い年(2020年)で約70万円です(以前のルールは年平均 約164万円、最大 約385万円)。
同じ段階で毎日追加すると +443%・年平均 約62万円、3日に1回なら +402%・約24万円でした。

## 売りのルール

基準価額が1年前(245営業日前)の3倍以上で、しかも積立の開始日(ページの設定)から買った持ち分に利益が出ている日は、
次の営業日に持ち分の1/4を売ります(合図は20営業日に1回まで)。
売ったお金(税引後)は暴落時の追加買いに先に使い、残りは基準価額が200日平均より20%以上安い日に、残りの10%ずつ買い戻します。

1996年〜(2017年12月より前は日経平均×4.3の合成値)の開始日を約3ヶ月ずつずらして「売らない」と比べると、
5年続けた回の90%で勝ち(7%は合図なしで同じ、中央値 +17%、いちばん負けた回 −5%)、3年では76%、1年では合図が出ないことが多くほぼ同じでした。
実際の基準価額だけ(2018年1月〜)では、税引後の資産÷入れたお金が ×5.8 → ×12.4、途中の最大の下げが −87% → −77%。
売った現金をそのまま置くと長期では大きく負けるので、買い戻しまでがひとつのルールです。
検証スクリプトはプロジェクトの共有フォルダ `sbi43bull/sell/` にあります。

## 条件の毎日見直し

基準価額が更新されるたびに `scripts/optimize.py` が、いろいろな種類のルール(追加買い 6種類166通り・売り 5種類405通り)を1996年〜最新の基準価額で計算し直し、
今のルールと比べた結果を `data/optimize.json` に書きます(数秒で終わります)。ページの「条件の毎日見直し」に表示します。
**ページの実際のルール(app.js)は自動では変わりません。** 「見直し候補あり」が続いたら、採るかどうかを決めて app.js を直します。

- 比べ方: 開始日を約1ヶ月(売りは約3ヶ月)ずつずらした3年・5年の期間で、追加買いは今のルールと、売りは「売らない」と比べた倍率の中央値
- 追加買いの種類: N日高値からの下落(今のルールの仲間)/移動平均からの下落/RSI(売られすぎ)/変動率で割った下落/1年高値からの下落に比例/大きな下げからの反発
- 売りの種類: 1年前の何倍(今のルールの仲間)/200日平均の何倍/RSI(買われすぎ)/大きく上がったあとの下げはじめ/自分の持ち分の含み益。どれも売る割合(1/5〜全部)と買い戻しの目安を組み合わせる
- たまたま当たった条件を選ばないために:
  - すぐ隣の条件も平均した成績で選ぶ
  - 追加買いは、1年で要る追加の現金が今のルールの1.1倍を超えるもの、5年でいちばん負けた回が −15% より悪いものは選ばない
  - 売りは、5年でいちばん負けた回が −10% より悪い条件は選ばない
  - ウォークフォワード: 各年について「その年より前のデータだけで選んだ条件」がその後3年で今のルールに勝ったかを確かめ、負け越すなら候補にしない
  - 今のルールとの差が十分(追加買い 5年の中央値 +2%以上・5年で勝ち60%以上など、売り +3ポイント以上)なときだけ「見直し候補あり」
- `data/nikkei_1996-2017.json` は、2017年12月より前の仮の基準価額(日経平均の日次騰落×4.3＋年3.39%)を作るための日経平均の終値

## 表示している内容

- 今日のアドバイス: 最新の基準価額での判定と、次の営業日の注文額。各段階になる基準価額の目安
- 売り時の判定: 1年前比・200日平均からの位置と、売る/持ち続ける/買い戻すの目安の基準価額
- 基準価額・前日比・20日高値から・過去最高値から・1ヶ月・1年
- チャート: 基準価額と20日高値(追加買いの日に印)、20日高値からの下落率(段階のライン付き)。期間は 3ヶ月/1年/3年/全期間
- 自分の積立シミュレーション: 開始日・毎日の金額・追加額の大きさを入れると、ルールどおりに買った場合の損益を計算
  (設定は閲覧しているブラウザの localStorage にだけ保存)
- このルールの過去の成績: 年ごとの「毎日だけ」と「追加ルールあり」の比較
- 売りルールの決め方と過去の成績: 検証結果の表と、実際の基準価額で出た売りの合図とそのあとの値動き
- **投資助言ではありません。** 売買判断はご自身の責任で行ってください

## データについて

- `data/nav.json` — 設定来の日次基準価額(円/1万口)。手で編集しない
  - `.github/workflows/update-nikkei43.yml` が平日 20:30・22:30 と翌朝 7:30(JST)頃に `scripts/fetch_nav.py` を実行し、
    新しい日の基準価額を追記してコミットし、GitHub Pages を再デプロイします
  - 取得元は投資信託協会「投信総合検索ライブラリー」の基準価額CSV。取れないときは Yahoo!ファイナンスの時系列ページ
  - 取得した値が既存データと食い違う、1日で60%を超えて動くなど、おかしな値のときは上書きしません
  - 手で更新したいときは、ページの「今すぐ更新」から Issue を作る(所有者が作ると `.github/workflows/request-nikkei43-update.yml` が更新を起動)か、GitHub の Actions タブ →「日経4.3ブル基準価額更新」→「Run workflow」
  - ページの「最新データを読み込む」は、ページを開いたまま `nav.json` をキャッシュなしで取り直して描き直します

## ファイル構成

- `index.html` — ページ本体
- `assets/style.css` — スタイル(portal と同じデザイントークン)
- `assets/app.js` — 下落率・追加額・シミュレーションの計算とチャート描画
- `scripts/optimize.py` — 買い時・売り時の条件を計算し直して `data/optimize.json` を書くスクリプト(標準ライブラリのみ)
- `scripts/fetch_nav.py` — 基準価額を取得して `data/nav.json` に追記するスクリプト(標準ライブラリのみ)
