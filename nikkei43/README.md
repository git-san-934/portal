# nikkei43(日経4.3ブル 暴落買いナビ)

SBI日本株4.3ブル(協会コード 8931317C)の基準価額を毎日分析して、毎日の積立(初期値 1万円)に
上乗せする「暴落時の追加額」と、上がりすぎたときの「売り時」の目安を出すページです。サーバーは持たない静的サイトです。

## 公開URL

https://git-san-934.github.io/portal/nikkei43/

## 追加買いのルール

その日の基準価額が「直近20営業日の最高値」から何%下がったかで、次の営業日の追加額を決めます。

| 20日高値からの下落 | 追加額(ふつう) | 控えめ(½) | 多め(×2) |
|---|---|---|---|
| −30%より浅い | なし | なし | なし |
| −30%以下 | 3万円 | 1.5万円 | 6万円 |
| −40%以下 | 6万円 | 3万円 | 12万円 |
| −50%以下(大口) | 30万円 | 15万円 | 60万円 |
| −70%以下(大口) | 50万円 | 25万円 | 100万円 |

大口買いは1回の暴落で合計200万円(½なら100万円、×2なら400万円)まで。使い切ったあとは10万円ずつ続けます。
大口の合図が60営業日なければ、次は別の暴落として数え直します。リーマンショックのように下げが何ヶ月も続くと、
上限なしでは1回の暴落で1,800万円ほど必要になり、しかも3年後に約8割下がっていたための歯止めです。

2017年12月〜2026年9月の基準価額で検証すると(毎日1万円+ふつう、合図の翌営業日に購入)、
追加ありの方が 9年中 9年で投資額あたりの損益率が良く、全期間では 毎日だけ +613% → +851% でした
(以前の「−50%で10万円」までのルールは +765%)。追加額は年平均 約150万円、最も多い年(2020年)で約370万円です。

## 売りのルール

基準価額が1年前(245営業日前)の3倍以上になった日は、次の営業日に持ち分の1/4を売ります(合図は20営業日に1回まで)。
売ったお金(税引後)は暴落時の追加買いに先に使い、残りは基準価額が200日平均より20%以上安い日に、残りの10%ずつ買い戻します。

1996年〜(2017年12月より前は日経平均×4.3の合成値)の開始日を約3ヶ月ずつずらして「売らない」と比べると、
5年続けた回の97%で勝ち(中央値 +20%、いちばん負けた回 −5%)、3年では79%、1年では合図が出ないことが多くほぼ同じでした。
実際の基準価額だけ(2018年1月〜)では、税引後の資産÷入れたお金が ×6.2 → ×12.4、途中の最大の下げが −87% → −77%。
売った現金をそのまま置くと長期では大きく負けるので、買い戻しまでがひとつのルールです。
検証スクリプトはプロジェクトの共有フォルダ `sbi43bull/sell/` にあります。

## 表示している内容

- 今日のアドバイス: 最新の基準価額での判定と、次の営業日の注文額。各段階になる基準価額の目安
- 売り時の判定: 1年前比・200日平均からの位置と、売る/持ち続ける/買い戻すの目安の基準価額
- 基準価額・前日比・20日高値から・過去最高値から・1ヶ月・1年
- チャート: 基準価額と20日高値(追加買いの日に印)、20日高値からの下落率(段階のライン付き)。期間は 3ヶ月/1年/3年/全期間
- 自分の積立シミュレーション: 開始日・毎日の金額・追加額の大きさを入れると、ルールどおりに買った場合の損益を計算
  (設定は閲覧しているブラウザの localStorage にだけ保存)
- このルールの過去の成績: 年ごとの「毎日だけ」と「追加ルールあり」の比較
- 売りルールの決め方と過去の成績: 検証結果の表と、実際の基準価額で出た売りの合図とそのあとの値動き
- **投資助言ではありません。** 売買判断はご自身の責任で行ってください

## データについて

- `data/nav.json` — 設定来の日次基準価額(円/1万口)。手で編集しない
  - `.github/workflows/update-nikkei43.yml` が平日 20:30・22:30 と翌朝 7:30(JST)頃に `scripts/fetch_nav.py` を実行し、
    新しい日の基準価額を追記してコミットし、GitHub Pages を再デプロイします
  - 取得元は投資信託協会「投信総合検索ライブラリー」の基準価額CSV。取れないときは Yahoo!ファイナンスの時系列ページ
  - 取得した値が既存データと食い違う、1日で60%を超えて動くなど、おかしな値のときは上書きしません
  - 手で更新したいときは、ページの「今すぐ更新」から Issue を作る(所有者が作ると `.github/workflows/request-nikkei43-update.yml` が更新を起動)か、GitHub の Actions タブ →「日経4.3ブル基準価額更新」→「Run workflow」
  - ページの「最新データを読み込む」は、ページを開いたまま `nav.json` をキャッシュなしで取り直して描き直します

## ファイル構成

- `index.html` — ページ本体
- `assets/style.css` — スタイル(portal / sector-etf と同じデザイントークン)
- `assets/app.js` — 下落率・追加額・シミュレーションの計算とチャート描画
- `scripts/fetch_nav.py` — 基準価額を取得して `data/nav.json` に追記するスクリプト(標準ライブラリのみ)
