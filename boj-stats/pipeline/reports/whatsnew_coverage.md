# 日銀「新着情報」過去1年（2025年9月〜2026年9月）の統計と取り込み状況

2026-09-28 時点。新着情報の「統計」カテゴリに載った約40種類を、日銀の統計API（時系列統計データ検索サイト）で取れるかどうかで仕分けした。

## APIにあるが今回は見送り（希望があれば追加）

- 業態別の日銀当座預金残高（MD08、超過準備など）
- 決済動向（PS01）、フェイルの発生状況（PS02）
- BIS国際資金取引統計・国際与信統計（BIS）、デリバティブ定例市場報告（DER）
- 対外資産負債残高、業種別・地域別直接投資（BP01）

## APIに無く、ExcelやPDFの個別ファイルだけのもの（見送り）

- 日本銀行が保有する国債の銘柄別残高（旬ごとのExcel。月次の長期国債残高はBS01で取得済み）
- オペレーション、日本銀行の対政府取引、日本銀行が受入れている担保の残高
- 地域の業況判断DI（関東甲信越・東海）、FSBレポ統計、保有外貨資産、銀行券・貨幣受払高

## 日銀以外が作る統計

- 消費者物価指数（総務省）：総合・生鮮食品を除く総合・生鮮食品及びエネルギーを除く総合の前年比を取り込み済み（2021年1月〜）。

# 総務省統計局「新着情報」の統計と取り込み状況（2026-09-28）

統計局の新着情報ページには直近1か月分しか載らず、過去分の一覧もない。そこで公表スケジュールにある毎月の定例統計と、過去1年に公表された年次・周期調査で仕分けした。

| 統計 | 状況 |
|---|---|
| 消費者物価指数（全国） | 取り込み済み：総合・コア・コアコア前年比（2021年1月〜） |
| 消費者物価指数（東京都区部） | 取り込み済み：総合・コア・コアコア前年比（2025年基準のため2026年1月〜） |
| 消費動向指数（CTI） | 取り込み済み：総消費動向指数（実質）と前年比（2017年〜） |
| 家計調査（二人以上の世帯） | 取り込み済み：消費支出・財・サービスの実質前年比（2001年〜）、消費支出額（2000年〜） |
| 小売物価統計調査 | 取り込み済み：東京都区部のコメ（コシヒカリ5kg）・鶏卵・ガソリンの店頭価格（2025年8月〜、毎月たまっていく） |
| 労働力調査（失業率など） | 取り込み済み：完全失業率・就業者数（季節調整値、1953年1月〜、e-Stat のExcel） |
| サービス産業動態統計調査 | 取り込み済み：売上高前年比（サービス産業計・情報通信業・宿泊業，飲食サービス業）、2014-01〜 |
| 人口推計 | 取り込み済み：総人口（各月1日）と社会増減 |
| 住民基本台帳人口移動報告 | 取り込み済み：東京圏・東京都の転入超過数（2025年3月〜、2025年9月は欠け） |
| 家計消費状況調査 | 見送り：家計調査と内容が重なる（ネット購入額など） |

過去1年に公表された年次・数年ごとの調査（令和6年全国家計構造調査、小売物価統計の構造編、科学技術研究調査、個人企業経済調査など）は年1回以下の更新で、毎朝の変化検知には向かないため見送り。必要なら個別に取り出す。
