ボックス上放れ

ダーバスのボックス理論で、東証（プライム・スタンダード・グロース）の全銘柄から、ボックスを上に抜けた買いの合図と、損切りラインを割った売りの合図を毎日出します。

買いの合図

最新の終値でボックスの上限を上抜けた銘柄です。ルールでは翌営業日の寄付きで買います。

売りの合図

保有中（シミュレーション）の銘柄のうち、最新の終値で損切りラインを割った銘柄です。翌営業日の寄付きで売ります。

保有中の銘柄と損切りライン

過去1年に買いの合図が出て、まだ売りの合図が出ていない銘柄です。損切りラインは新しいボックスができるたびに上がります。

上放れ間近

ボックスができていて、終値が上限まで5%以内の銘柄です。

銘柄終値上限まで業績四半期 売上／営業利益上限下限ボックス幅日数

これまでの合図

    売買のルール（日足、分割調整済み）

    1. 52週の新高値をつけた後、3日間その高値を超えなければ、そこがボックスの上限
    2. その後3日間安値を更新しなければ、そこがボックスの下限
    3. ボックス幅15%以内、ボックス期間10日以上、50日平均の売買代金5,000万円以上
    4. 買い：終値が上限を上抜けたら、翌営業日の寄付きで買う
    5. 損切りライン：ボックスの下限の10%下。保有中に新しいボックスができるたびに引き上げる（下げない）
    6. 売り：終値が損切りラインを割ったら、翌営業日の寄付きで売る。利益確定の目標値は置かない

    業績の4条件（Yahoo Finance の決算から判定。緑が満たしている条件）：①前の年も通期の営業利益+5%以上　②直近の通期営業利益+20%以上　③直近の四半期の営業利益が前年同期比+20%以上かつ売上+10%以上（最も重要）　④通期の営業利益率が改善。Yahoo は日本株の決算の反映が1四半期ほど遅れることがあります。

    ビッグチェンジ（新製品・新事業・M&A・政策・新経営陣）は自動では判定できません。買いの合図の銘柄にはニュースと適時開示へのリンクを付けているので、そこで確認してください。データは Yahoo Finance から平日の夕方と夜に GitHub Actions が自動で更新します。機械的な判定で、投資の助言ではありません。
