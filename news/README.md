# 持ち株の新着情報

https://git-san-934.github.io/portal/news/

持ち株の新しい情報を集めて、日付・リンクつきの箇条書きで表示します。

## 集める情報

| 情報源 | 対象 | 内容 |
|---|---|---|
| 公式サイト | 全銘柄 | 各社のニュース・IRニュース一覧のページから、日付つきのリンクを拾う(RSS があればそれも読む) |
| EDINET | 日本株 | その会社が出した書類(有価証券報告書・半期報告書・臨時報告書・自己株券買付状況報告書など)と、他社が出したその会社の大量保有報告書。直近90日 |
| SEC EDGAR | 米国株 | 8-K・10-Q・10-K・大量保有報告(13D/13G)など。直近120日 |

「新着」は、このページがはじめて見つけてから3日以内のものです。

## 更新のタイミング

`.github/workflows/update-news.yml` が毎日 1:00・8:30・12:45・15:45(日本時間)に動きます。
GitHub 側の混雑で数分〜数十分遅れることがあります。Actions の画面から手動でも実行できます。

## 設定

- 銘柄: 「持ち株チェック」と共通(`holdings/data/holdings.json`)。持ち株チェックのページで銘柄リストを保存すると、こちらも更新されます。
- 公式サイトのURL: `data/sources.json`。`home` はトップページ、`pages` はニュース一覧のページ(RSS も可)。
  `pages` から取れないときは、`home` からニュース一覧らしいページを自動で探します。
  新しい銘柄を加えたときは、ここにも1行足してください(無くても EDINET・SEC の情報は載ります)。
- EDINET: リポジトリの Secrets の `EDINET_API_KEY`(他のアプリと共通)を使います。

## ファイル

- `scripts/fetch_news.py` — 情報を集めて `data/news.json` を作る
- `data/news.json` — ページが読むデータ。前回はじめて見つけた時刻(`first_seen`)を引き継ぐ
- `data/edinet_cache.json` — EDINET の書類一覧のキャッシュ(確定した日は読み直さない)
