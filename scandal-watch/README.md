# scandal-watch(不祥事株のその後)

「不祥事で下がった株は、本来の価値より安くなることがある」という考えを、実際の例で確かめるページです。
ここ5年(2021〜2026年)に不祥事があった上場企業について、何が起きたか・一時的な問題か本業に響く問題か・
その後の株価の動きを一覧にしています。サーバーは持たない静的サイトです。

## 公開URL

https://git-san-934.github.io/portal/scandal-watch/

## 見られるもの

- 不祥事ごとのカード: 何が起きたか / 分類とその理由 / その後(処分・業績など) / 出典
- 分類は3つ: 一時的(本業の稼ぐ力は大きく変わらない) / 本業に響く(信頼や稼ぐ力そのものが傷ついた) / 見きわめ中
- 株価の動き: 不祥事が知られた日の前の営業日の終値を基準に、1週間後・半年以内の底・1年後・今の騰落率と、TOPIXとの差
- 基準日を100とした株価とTOPIXの週足チャート(基準日の約1年前から)
- 分類ごとの成績: 1年後のTOPIXとの差(中央値)と、TOPIXを上回った件数
- わたしの判断(PDCA): 銘柄ごとに「買いたい・様子を見る・見送る」と理由を記録すると、記録したときの株価と今の株価を並べて表示
  (この端末のブラウザにだけ保存)

## データについて

- `data/cases.json` — 不祥事の一覧。手で調べて書いたもの。1件ごとに出典(記事・会社や官庁の発表)を3つつけている
  - `date` は問題が最初に広く知られた日(公表・報道・逮捕・処分など)
  - `type` は `temporary`(一時的)/ `core`(本業に響く)/ `watch`(見きわめ中)。このページの見立てで、正解ではない
  - 例を増やすときは、同じ形のかたまりを1つ足す
- `data/prices.json` — 株価から計算した値(自動生成)。株価は Yahoo Finance(yfinance 経由)。株式分割を調整した終値で、配当は含まない
- `.github/workflows/update-scandal-watch.yml` が平日 16:45(JST)頃に `scripts/fetch_prices.py` を実行し、
  `data/prices.json` を更新してコミットし、GitHub Pages を再デプロイします
- 手動で更新したいときは、GitHub の Actions タブ →「不祥事株データ更新」→「Run workflow」

## 注意点

- 上場廃止になった銘柄(日医工・オルツなど)は Yahoo から株価が取れないことが多く、その場合は数字が出ません。
  そのため「分類ごとの成績」は実際より良く見えやすくなります(特に「本業に響く」)
- 取り上げた例は、よく報道された大きな不祥事が中心です。すべての不祥事を網羅したものではありません
- 株価の動きには、不祥事以外の理由(相場全体・業績・株主還元など)も混ざっています
- **投資助言ではありません。** 売買判断はご自身の責任で行ってください
